# POS ขายสินค้า (มือถือ)

เว็บแอพ POS สำหรับร้านค้า ใช้บนมือถือเครื่องเดียว ติดตั้งเป็นแอพได้ (PWA) และใช้งานออฟไลน์ได้

## ความสามารถ
- เลือกสินค้าได้ 3 แบบ: พิมพ์ชื่อ/รหัส, เลือกจากรายการ, สแกนบาร์โค้ด/QR ด้วยกล้อง (รองรับเครื่องสแกนบลูทูธ/USB ที่พิมพ์แล้วกด Enter)
- พิมพ์ `3*11111` เพื่อเพิ่มจำนวน 3 ชิ้นทีเดียว
- แก้ไขรายการในบิล: เพิ่ม/ลดจำนวน, ส่วนลดรายการ (บาท หรือ %), ส่วนลดท้ายบิล, ลบรายการ
- เปลี่ยนหน่วยนับได้ (เช่น ชิ้น → แพค) โดยรหัสสินค้าและราคาจะเปลี่ยนตามหน่วยนั้นอัตโนมัติ
- ฐานข้อมูลสินค้า: 1 สินค้ามีหลายหน่วย แต่ละหน่วยมีรหัสและราคาของตัวเอง, นำเข้า/ส่งออก CSV
- **เช็คบิล ก่อนออกใบเสร็จ**: แสดงรายการ + ยอด + **QR พร้อมเพย์ที่ฝังยอดเงินไว้แล้ว** ลูกค้าสแกนด้วยแอพธนาคารได้ทันที · ส่งบิลเป็นรูป (LINE) หรือพิมพ์บิลพร้อม QR ได้ · กด "รับเงินสด" หรือ "รับโอนแล้ว" แล้วบิลจะกลายเป็นใบเสร็จ
- บันทึกบิล **ค้างชำระ** (ใส่ชื่อลูกค้า/หมายเหตุได้) แล้วกลับมารับเงินทีหลังที่แท็บรายงาน · บิลค้างไม่นับในยอดขายและไม่ถูกลบอัตโนมัติ
- ตั้งค่าพร้อมเพย์ (เบอร์มือถือ / เลขบัตรประชาชน / เลขผู้เสียภาษี) และเลขบัญชีธนาคารสำรองที่แสดงบนบิล · ถ้ายังไม่ตั้งค่า บิลจะยังใช้ได้แต่ไม่มี QR
- รายงานยอดขาย ช่วงวันที่, สินค้าขายดี, ดู/ลบบิล, ส่งออก CSV
- ตั้งค่าระยะเวลาเก็บประวัติการขาย (7 วัน – 2 ปี หรือเก็บตลอด) ระบบลบบิลเก่าให้อัตโนมัติ
- สำรอง/กู้คืนข้อมูลเป็นไฟล์ JSON

## การเก็บข้อมูล
ข้อมูลทั้งหมดเก็บใน IndexedDB ของเบราว์เซอร์บนมือถือเครื่องนั้น ไม่มีเซิร์ฟเวอร์ ไม่ต้องตั้งค่าฐานข้อมูล

## Deploy
เป็นเว็บ static ล้วน (ไม่ต้อง build) — import repo นี้เข้า Vercel แล้วกด Deploy ได้เลย

ใช้ไลบรารี [html5-qrcode](https://github.com/mebjas/html5-qrcode) (Apache-2.0) สำหรับสแกน และ [qrcode-generator](https://github.com/kazuhikoarase/qrcode-generator) (MIT) สำหรับสร้าง QR

หมายเหตุ: QR พร้อมเพย์สร้างในเครื่องตามมาตรฐาน EMVCo ไม่ต้องใช้ API ธนาคาร แอพจึงตรวจไม่ได้ว่าเงินเข้าแล้ว ผู้ขายต้องดูแจ้งเตือนจากแอพธนาคารก่อนกด "รับโอนแล้ว"
